## 中文

HTTP Client 0.1.2 预览版：更紧凑的请求工作台，支持打开请求文件、恢复会话历史和保存响应。

### 更新内容

- 打开 `.http` / `.rest` 文件后直接列出请求；请求编辑区支持语法高亮、行号、撤销和请求定位。
- 增加本次会话的请求历史，可恢复或清空；关闭页面后不保留草稿和历史。
- 请求与响应面板支持拖动、键盘调节和双击恢复，窄窗口自动上下排列。
- 预览上限默认改为 **128 KiB**，可在 1–512 KiB 之间按 1 KiB 调整。
- 改善响应头字体、对比度和行距，增加正文换行／横向滚动切换。
- 支持保存原始正文或“响应头 + 正文”；截断的响应仅导出已收到的预览内容。
- HTML 正文默认收起开头的空行，可随时展开原文；选择保存到工作区后可在编辑区打开 HTML 预览。
- 更新深浅主题、状态反馈和极简地球图标，修复空编辑器出现三行高光标的问题。

### 安装与兼容性

下载 `http-client-0.1.2-darwin.zip`，在 Lithe 插件管理中选择从磁盘安装；一个包同时包含 Apple Silicon 和 Intel 代码，旁边的 `.sha256` 文件用于核验下载内容。

需要支持插件 API 3 和 `backend: 2`、`serverProcess: 1`、`ui: 2` 的 macOS Lithe。文件选择和保存需要 Web bridge 2；HTML 预览还需要本地工作区及相应宿主能力。本版新增工作区元数据、文档摘要和 HTML 预览权限，用于定位预览文件并避免覆盖已打开的文档。

仍为社区预览版，使用 ad-hoc 可执行文件签名，未做开发者签名或公证；Windows 不支持。原生文件对话框、编辑区 HTML 预览的完整验收及 Intel 硬件运行验收仍待完成。浏览器验证覆盖 Chrome 和 WebKit，不能替代上述宿主验收。不会自动保存请求；只有明确选择保存或预览时才写入所选文件。

## English

HTTP Client 0.1.2 preview brings a compact request workbench with request-file loading, session history and response exports.

### Changes

- Open `.http` / `.rest` files to list their requests, with syntax highlighting, line numbers, undo and navigation in the request editor.
- Restore or clear requests from the current session; drafts and history are discarded when the page closes.
- Resize the request/response panes with the pointer or keyboard, double-click to reset, and use a stacked layout in narrow windows.
- The body preview now defaults to **128 KiB**, adjustable from 1–512 KiB in 1 KiB steps.
- Read headers with improved typography, contrast and spacing, and switch the body between line wrapping and horizontal scrolling.
- Save the original body or headers plus body; a truncated response exports only the available preview.
- Collapse leading blank HTML lines with an option to restore the original view, or save HTML inside the workspace and open its editor preview.
- Refine light/dark themes, operation feedback and the minimal globe icon, and fix the three-line-high caret in an empty editor.

### Installation and compatibility

Download `http-client-0.1.2-darwin.zip` and use Lithe's install-from-disk action. The same package contains Apple Silicon and Intel code; the adjacent `.sha256` file verifies the download.

Requires macOS Lithe with plugin API 3 and `backend: 2`, `serverProcess: 1`, `ui: 2`. File dialogs need Web bridge 2; HTML preview also needs a local workspace and the corresponding host service. This version adds workspace-metadata, document-summary and HTML-preview permissions to locate preview files and avoid overwriting open documents.

This remains a community preview with an ad-hoc signed executable, without publisher signing or notarization. Windows is unsupported. Full native file-dialog/editor-preview acceptance and Intel hardware acceptance are still pending. Chrome and WebKit verification does not replace those checks. Requests are not saved automatically; only an explicit save or preview writes the selected file.
