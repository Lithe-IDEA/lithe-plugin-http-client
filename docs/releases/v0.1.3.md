## 中文

HTTP Client 0.1.3 预览版接入 Lithe 的结构化插件诊断（`litheLogging` 1）。需要提供 `litheLogging` 1 的 Lithe preview 开发版；稳定版 Lithe 0.6.7 能安装但无法启动后端，请在稳定版上继续使用 Lithe Store 中的 0.1.2。

### 更新内容

- 后端改用官方 Rust SDK 的结构化日志，诊断写入 Lithe 日志窗口中本次会话的 `plugins/io.github.lithe-idea.http-client/host` 通道，级别、脱敏、轮转和保留由宿主统一决定。
- 每个后端函数由 SDK 记录唯一的成功或失败终态，带函数 ID、耗时和安全的错误分类；取消不算失败。
- 高频的请求解析（`requests.parse`）和预览能力探测（`response.previewInfo`）成功时不再记 INFO，失败照常记 ERROR。
- 响应预览达到大小上限被截断时，每次后端运行只记一次 `preview_truncated` 降级。
- 诊断不含 URL、请求或响应正文、头部、环境变量、凭据、文件路径或所选文件内容；启动在协议通道建立前失败时以退出码结束，不再向 stderr 打印。
- 官方 Rust SDK 改为仓库内的 vendor 副本，CI 与打包按逐文件 SHA-256 校验；`NOTICE` 和 README 中的 SDK 许可证更正为 Apache-2.0。
- 请求编辑、会话历史、响应导出和 HTML 预览等功能与 0.1.2 相同。

### 安装与兼容性

预发布版本会被 Lithe Store 自动追踪跳过，暂不收录 Store。下载 `http-client-0.1.3-darwin.zip`，在「设置 → 插件」的 ⚙ 菜单中选择「从磁盘安装插件…」导入；一个包同时包含 Apple Silicon 和 Intel 代码，旁边的 `.sha256` 文件用于核验下载内容。

需要支持插件 API 3 和 `backend: 2`、`serverProcess: 1`、`ui: 2` 的 macOS Lithe，并且宿主要提供 `litheLogging` 1。权限声明与 0.1.2 相同。

仍为社区预览版，使用 ad-hoc 可执行文件签名，未做开发者签名或公证；Windows 不支持。协议测试会协商 `litheLogging` 1 并检查诊断帧与隐私；在 Lithe 日志窗口中的端到端验收、原生文件对话框、编辑区 HTML 预览和 Intel 硬件运行验收仍待完成。

## English

HTTP Client 0.1.3 preview adopts Lithe's structured plugin diagnostics (`litheLogging` 1). It needs a Lithe preview build that offers `litheLogging` 1. Stable Lithe 0.6.7 installs it but cannot start its backend; keep 0.1.2 from Lithe Store there.

### Changes

- The backend uses the official Rust SDK's structured logging. Diagnostics go to the current session's `plugins/io.github.lithe-idea.http-client/host` channel in Lithe's log window; the host decides levels, redaction, rotation and retention.
- The SDK records exactly one success or failure for each backend function, with its function ID, duration and a safe error category; cancellation is not a failure.
- Successful request parsing (`requests.parse`) and preview capability probes (`response.previewInfo`) no longer log INFO; failures still log ERROR.
- When a response preview is truncated at its size limit, one `preview_truncated` degradation is logged per backend run.
- Diagnostics never contain URLs, request or response bodies, headers, environment variables, credentials, file paths or selected file contents. A startup failure before the protocol channel opens exits with a status code and no longer prints to stderr.
- The official Rust SDK is vendored in the repository; CI and packaging verify every file's SHA-256. `NOTICE` and the README now give the SDK's license correctly as Apache-2.0.
- Request editing, session history, response exports and HTML preview are unchanged from 0.1.2.

### Installation and compatibility

Lithe Store's tracker skips pre-releases, so this version is not listed in the Store. Download `http-client-0.1.3-darwin.zip` and import it with Install Plugin from Disk… in the ⚙ menu of Settings → Plugins. The same package contains Apple Silicon and Intel code; the adjacent `.sha256` file verifies the download.

Requires macOS Lithe with plugin API 3 and `backend: 2`, `serverProcess: 1`, `ui: 2`, and a host offering `litheLogging` 1. Permissions are unchanged from 0.1.2.

This remains a community preview with an ad-hoc signed executable, without publisher signing or notarization. Windows is unsupported. Protocol tests negotiate `litheLogging` 1 and check diagnostic frames and privacy; end-to-end acceptance in Lithe's log window, native file dialogs, the editor HTML preview and Intel hardware are still pending.
